# 灰灰和白白

一个用 Godot 制作的 3D 虚拟仓鼠游戏。你可以给灰灰和白白添粮、换水、换垫料，也可以把它们轻轻抱起来。照料进度和相册保存在设备上。

## 从源码运行

1. 安装 Godot 4.5.1。
2. 克隆仓库，用 Godot 项目管理器导入根目录的 `project.godot`。
3. 等待资源导入后，按 F5 运行项目。

桌面端用鼠标右键按住并拖动仓鼠，触屏端用双指捏住同一只仓鼠后移动。Android 导出和 iOS AR 插件的构建步骤见[安装与构建](安装与构建.md)。
